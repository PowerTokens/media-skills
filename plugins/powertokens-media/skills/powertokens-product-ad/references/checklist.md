# Delivery checklist
- [ ] If user gave a product URL: page fetched (or failure reported); claims extracted with `source_quote` + URL only — no invented specs
- [ ] At estimate time: one-line look note (default `clean-premium`; UGC/cinematic on request) — no forced picker
- [ ] Claim sheet shown and **approved** (`scripts/claim_sheet.py table` / `approve`); status allows spend
- [ ] Every hook/caption/VO/end-card line maps to an **approved** claim row (`references/copy.md`)
- [ ] No mood-only or brand-swappable lines; hooks encode a verified benefit in ≤ 2 s
- [ ] Captions match VO meaning; kinetic shortening did not invent or drop facts
- [ ] Product bible filled in order: **category → subtype → parts BOM → forbid** (+ colors, logos, proportions, 1–3 refs)
- [ ] Shot list has `"kind": "product-ad"` and `"product_bible"`; `pipeline validate` passes
- [ ] PRODUCT LOCK constraints present on every keyframe + i2v prompt (pipeline injects from bible)
- [ ] Same approved product refs reused across product-visible shots; no invented hybrid parts
- [ ] Hero / packshot keyframes human-OK (or vision QC pass) before i2v
- [ ] Product visible by 3 s; shape, label and colors match the real product in every shot
- [ ] No invented claims, prices, awards, or certifications; end-card price only if user-provided / on approved sheet
- [ ] Deliverable is the MP4 with captions **burned in** (`assemble` without `--no-captions`; JSON `captions_burned: true`, no `warning`). A sidecar `captions.srt`, or telling the user to open it, is incomplete unless they explicitly asked for softsubs only
- [ ] Every shot has `caption` text (or the VO line copied onto `caption`) so burn-in is not empty. If assemble warns that caption text is missing, fix the shot list and re-assemble before delivery
- [ ] Captions inside safe area (not under platform UI at bottom/right; prefer ~60% height); style defaults to `tiktok` (A), changeable (`pill` / `caps-punch` / `zh`) if user asks or copy is CJK
- [ ] Seedance i2v: no `ratio` param (follows first frame); keyframe already at platform ratio
- [ ] Ratio correct for the platform; duration within platform limits
- [ ] VO lines are original approved claims (no lyrics, verbatim slogans, celebrity endorsements, or long quotes); one TTS call per line
- [ ] A `CONTENT_POLICY` line was rewritten once or the user chose a new line; partial assemble only with their yes (`--allow-partial-vo`)
- [ ] Audio levels: VO clear over ambience / ducked BGM; no clipping
- [ ] File: H.264 MP4, 1080×1920, 30 fps (assemble default)
- [ ] Report spend estimate and file paths
