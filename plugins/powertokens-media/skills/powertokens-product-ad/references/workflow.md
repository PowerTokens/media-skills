# Product ad workflow details

## Copy first (do not skip)

Follow `copy.md` before any keyframe spend:

1. Claim sheet from user brief / provided PDP / visible pack only.
2. Reject mood-only and generic lines (`First light.`, `Premium adventure.`, brand-swappable praise).
3. Hook ≤2 s must carry a **verified** benefit or pattern break tied to that benefit.
4. Captions compress the same claims as VO; kinetic style shortens wording, never changes the fact.

## Hook formulas (first 1–2 s, on-screen + VO)

Only use a formula when the embedded claim is on the claim sheet:

- Result first: "6 a.m. Still hot." (hold-time approved)
- Pattern break: unexpected visual + question that names the pain the product solves
- Pain point: "Tired of cold coffee by 10?" (only if that failure mode is user-true)
- Demo first: product doing the claimed job in frame 1; caption states the claim, not the scenery

Write 2–3 hooks; use the rest as A/B variants (`powertokens-social-variants`).
If every draft fails the `copy.md` reject list, ask the user for sharper facts — do not ship atmospheric filler.

## Storyboard template (15 s, 9:16)

| # | Cut length | Shot | Motion/camera | Caption (claim) | VO |
|---|---|---|---|---|---|
| 1 | 2 s | hero close-up, product in context | slow push-in | hook claim | hook line |
| 2 | 3 s | product in use / proof demo | static or handheld | benefit 1 | benefit line |
| 3 | 3 s | detail/macro of the mechanism | orbit | benefit 2 / proof | proof line |
| 4 | 3 s | lifestyle wide only if it still sells a claim | pull-back | optional short claim | — |
| 5 | 3 s | packshot on clean bg | slow rotate | CTA | CTA line |

Draft clips use Seedance 2.0 Mini (`seedance-mini`): generate each at 4–5 s (minimum 4 s, maximum 15 s, 480p or 720p only — no 1080p, ~$0.031/s) and let assembly trim. Hero product turns stay on Kling (3–15 s, 1080p). Other models, if the user asks: Wan ≥ 2 s, Seedance ≥ 4 s.

## Product fidelity
- Use the real packshot as Seedream reference: "keep product shape, label and colors exactly as the reference".
- Prefer image-to-video from the keyframe over text-to-video for any shot where the product is readable.
- Small, slow motions keep labels stable; fast spins redraw them.
- **Third-party brand props are forbidden** in keyframes, i2v clips, VO / captions / end-cards, and finish overlays. No logos, wordmarks, packaging, or brand-identifiable devices (Apple MacBook / iPhone / logo, Nike swoosh, Starbucks cup mark, Amazon smile, Google/Microsoft hardware logos). Use a generic stand-in (plain silver laptop with no logo or chin text, blank phone bezel, plain mug). Exception only when the advertised SKU is that brand, or the user explicitly says they have rights or want that brand shown. Put `no third-party logos, wordmarks, or brand-identifiable devices (MacBook, iPhone, etc.) unless approved` in `immutable.forbid`. If a still or clip shows one, fail `logo_policy_ok` and regenerate or ask — do not ship.

## Keyframe QC gate (before any video)

Product-ad spends stills first and video second. `pipeline.py run` enforces this for `kind: product-ad`.

1. Unify the preview keyframes (usually 3–4 product stills).
2. Machine vision QC every keyframe (`qc: pass`).
3. On fail, regenerate **only that keyframe** once. Do not start i2v for siblings that already passed.
4. If the retry still fails, stop in the keyframe phase. Report which shots and why (structure, third-party logo, hybrid part, and the other rubric failures). Do not send failed stills to video.
5. Vision API down: fail closed, no video, unless `--skip-vision-qc`.
6. When every required keyframe has passed, submit i2v in one `--parallel` batch. Do not render shot video one-by-one while another still is in QC.
7. Human review of the full still strip is optional and **off by default**. `"hero": true` still pauses for `approve-hero` (or `--auto-approve-hero`). If the user asks to see the preview stills, show them before video; do not force a picker every run.

## Audio
- Clips with `audio: false` when VO carries the ad; set `assembly.clip_audio_volume` for ambience.
- No licensed music is generated by this pack; add music only from the user's own library.
- One MiniMax call per VO line (`speech-2.8-turbo` unless the user asks for HD). Lines are original claims from the approved sheet, not lyrics, verbatim slogans, celebrity endorsements, or long quotes. Say so before EN VO spend.
- `CONTENT_POLICY` on one line: the pipeline rewrites and retries that line once, then continues the other lines. Ask the user with the rejected line and rewrite options. Assemble does **not** require every VO file once they accept a partial cut (`assemble --allow-partial-vo`: available VO, silence for the missing line, ducked clip audio / their BGM). Do not assemble that partial, or switch to a ZH-only cut, until they say yes.

## Cost example (estimate, list prices in `scripts/video.py`)
5 shots × 4 s Seedance 2.0 Mini 720p = 20 s × $0.031 = $0.62, + 1 Kling 1080p 3 s × $0.168 = $0.50,
+ Seedream keyframes and VO (not priced here). Mini is the same ~$0.031/s at 480p and 720p.

## Look presets (finish) — light user awareness

Finish polish uses three presets (`finish.py --preset`):

| Preset | Feel | When |
|---|---|---|
| `clean-premium` | clean commercial (default) | user just says "make a product ad" |
| `ugc-punchy` | faster, punchier, more native-social | user asks for UGC / creator / punchy |
| `cinematic` | slower, graded, filmic | user asks for cinematic / filmic |

**Do not** show a mandatory three-option menu. At estimate/approval time, mention the default in one sentence and that they can ask for UGC or cinematic. If they already named a look in the brief, pick that preset silently and still name it in the estimate line.

## Delivery

Hand over the assembled MP4 with captions burned in (`assemble` without `--no-captions`, JSON `captions_burned: true`). `captions.srt` is a sidecar. If shots have no caption text, put the claim or VO line on each `caption`, re-assemble, and only then share the path. `--no-captions` is only for an explicit request for softsubs only or no burn-in.
