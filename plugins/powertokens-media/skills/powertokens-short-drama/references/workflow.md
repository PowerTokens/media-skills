# Short-drama structure

Episode (60–90 s, 9:16):
1. Cold open hook (0–3 s): the most intriguing image/line.
2. Setup (3–15 s): who, where, want.
3. Turn (15–45 s): obstacle/reveal.
4. Escalation (45–75 s): stakes rise.
5. Cliffhanger (last 3–5 s): unresolved question.

Shot list tips:
- Number shots `e01s01`…; keep a continuity note per shot (location, time, wardrobe, props).
- Alternate shot sizes (wide → medium → close-up) to hide small inconsistencies.
- Reaction shots (close-up face, 1–2 s) are cheap glue between story beats.
- Dialogue: one line per shot in quotes; long scenes → several shots.
- Across episodes: same location descriptions verbatim; open each episode with an establishing wide.

Video Studio's own sample episodes use 10 s 9:16 clips at 720P with a shared cast description
prepended to every prompt; this skill does the same via `characters`.
