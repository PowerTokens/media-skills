# Travel poster QA (before delivering)

- [ ] Aspect is 3:4 (or very close); upper and lower halves are visually 1:1.
- [ ] Upper half is clearly the **same** photo (identity, colors, light) — not a redraw or filter pass.
- [ ] Lower half is warm paper with real negative space — not a second scene photo.
- [ ] The second-world idea is specific to **this** photo (you can say which structure it came from).
- [ ] Cut / collage edge interprets the photo; not a lazy default tear every time.
- [ ] Figures (if any) ≤ 3, black line, doing something useful with the structure.
- [ ] Caption is one short English line, not a quote poster, placed near action/whitespace.
- [ ] No logos, watermarks, dense decoration, or brochure/ad look.
- [ ] Output path reported; user was asked before the paid Seedream call.
