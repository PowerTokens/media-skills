# UGC checklist
- [ ] Hooks/captions/spoken lines map to a sourced claim sheet (powertokens-product-ad `references/copy.md`); no mood-only filler
- [ ] Persona identical across shots (same ref image + same description)
- [ ] Persona is fictional; no real-person likeness; no fake "verified buyer" claims
- [ ] If a real product is on camera: use `powertokens-product-qc` bible (category → subtype → parts) or at least packshot refs + "structure unchanged"
- [ ] Lines are short, spoken, match captions
- [ ] Lip-sync acceptable on every face-cam shot (else switch that shot to VO over b-roll)
- [ ] Deliverable MP4 has captions burned in (`assemble` without `--no-captions`; `captions_burned: true`). SRT-only is incomplete unless the user asked for softsubs only
- [ ] Each shot has caption text (or the spoken line copied onto `caption`) so burn-in is not empty; an empty-SRT warning means fix the shot list and re-assemble
- [ ] Captions big, high contrast, inside safe area (~60% height; avoid bottom ~20% / right UI)
- [ ] Seedance i2v: no `ratio` with first_frame; keyframe already 9:16
- [ ] 2–3 hook variants delivered if requested
