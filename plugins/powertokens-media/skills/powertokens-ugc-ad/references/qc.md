# Optional post-assemble QC

Use this after `assemble` when the user wants a watch-pass. It is optional. The delivery checklist in `checklist.md` still applies. Do not spend credits for this pass.

Watch the MP4 once with sound. Do not judge from the JSON alone.

- [ ] `captions_burned` is true and the words are readable over the picture (not only in `captions.srt`)
- [ ] Caption text matches the spoken line; shortening did not add a new claim
- [ ] Every face shot matches the character bible (same face, hair, outfit). One outlier → re-take that shot only
- [ ] Hands-only shots stay hands-only
- [ ] If the pack is readable, shape and label match the product refs
- [ ] Props are generic. No competing brand mark that the user did not ask for
- [ ] CTA is the one they supplied
- [ ] No fake "real customer" or award line
- [ ] Safe area: captions around 60% height, not under the platform UI
- [ ] If a hook variant was requested, it is a separate file, not a silent overwrite of the main cut

If a row fails, name the shot id, fix the shot list or that clip, and assemble again. Say if the fix spends credits.
